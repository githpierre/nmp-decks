```yaml
title: Why has it become commoditized?
note: We see commoditization where AI data centers sell the same space, gear and services as every other site. New value therefore comes from power, speed, liquid cooling and long leases.

  9: AIR COOLING
  11: BACKUP POWER
  13: FIBER LINKS
  15: SECURITY
  17: REMOTE HANDS
  19: SMALL CAGES
  21: CLOUD ACCESS
  6: Because builders added huge amounts of standard space in the last decade
  8: Because the same cooling gear is sold to every builder by a few big suppliers
  10: Because generators and batteries are standard parts that any builder can buy
  12: Because carriers laid fiber to every hub to win data center clients
  14: Because insurers and big tenants ask for the same security rules everywhere
  16: Because local service firms offer the same help in every data center hub
  18: Because small tenants moved to the cloud and left plenty of cages empty
  20: Because the big clouds open their own links in every large site they can
```
